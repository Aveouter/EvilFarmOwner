## What changed

- No gameplay code changed from v0.5.1.
- Version metadata now reports v0.5.2.
- README and release notes now state the testing risk directly in English and Chinese.

## Known risk areas

- Complex route planning around dense crops, fences, machines, gates, sheds, and greenhouse paths.
- Classified-chest delivery and storage-sort behavior on unusual chest layouts.
- Wage settlement edge cases after interrupted or partially completed shifts.
- Multiplayer and multiworker behavior beyond the limited automated checks.
- Compatibility with other economy, automation, storage, and NPC-control mods.

## Player guidance

- Back up your save before using this build.
- Prefer a duplicate test save for the first run.
- If a worker stops unexpectedly or a HUD message looks inconsistent, preserve `SMAPI-latest.txt` before restarting.
- Report issues with the save date, map, worker name, screenshot, and SMAPI log.
